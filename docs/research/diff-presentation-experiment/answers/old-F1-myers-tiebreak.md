# old-F1-myers-tiebreak

> 作答代理只看 `arms/old-F1-myers-tiebreak.txt`。

Q1: diff 里没有文件头/函数名，看不出落在哪个文件哪个函数；从内容（`for (let k = -d; k <= d; k += 2)` + `v[mid + k ± 1]` + `trace.push(v.slice())`）可辨认这是 Myers 前向"最远可达点"循环（带 trace 回溯版本）内部的 k 对角线分支体。
Q2: 语义是平局裁决方向翻转：改前仅当 `v[mid+k-1] < v[mid+k+1]` 才取 `x = v[mid+k+1]`（down 移动，沿 b 前进/插入），相等时走 else `x = v[mid+k-1]+1`（right 移动，沿 a 前进/删除）；改成 `<=` 后相等也走 down 分支。即最小编辑距离不变，但同距离的最小 diff 在平局处由"删优先"变为"插优先"，产出的具体 diff 内容可能不同。
Q3: 仅当 `-d < k < d`（`k === -d` 已被第一个析取项短路，`k !== d` 把 k=d 钉死在 else）且 `v[mid+k-1] === v[mid+k+1]` 恰好相等时，改动才改变分支选择；严格小于/大于时两版行为一致。
Q4: 对该函数其他分支无影响（k=±d 与严格不等情形两版完全相同，diff 上下文可见）；对外部调用者方向是"行为基本等价但平局处 diff 内容可能变化"——Myers 对任意平局裁决都仍返回最小编辑距离的合法 diff；但函数签名/返回结构/调用方代码 diff 中均不可见，具体调用面从 diff 看不出来。
