# 验收实验结果：旧格式 vs 新格式（unified diff + @@ 段头）

> 目的：量一量「模型拿到 `edit` 的 diff 之后，能不能读懂被改的那个函数」。
> 唯一变量：**diff 的呈现形态**。素材、提示词、模型、题面全部相同。

## 方法

- **两臂**：
  - `old` = 改动前的生产代码渲染（`baseline-old-format.md`，已冻结）
  - `new` = 改动后的生产代码渲染（`candidate-new-format.md`，由 `lib/render/edit-diff.js` 的 `genDiff` + `lib/domain/edit/edit-response.js` 的 `renderUnifiedDiff` 渲染）
- **素材**：8 个 fixture（`fixtures.mjs`），覆盖改一行 / 合并分支 / 改排序键 / 重排判定条件 / 改阈值 / 整函数删除 / 同一段两处删除 / 一个文件三处远距改动。
- **两臂的输入文件**：`arms/<arm>-<fixture>.txt`，每个文件**只有那一份 diff**，不含标题、不含答案（标题里就有答案，会泄漏）。
- **提示词**：`ANSWER-PROMPT.md`，两臂逐字相同。
- **模型**：两臂同一个（见下「模型替换」一节）。
- **题目**：四问（定位 / 语义 / 条件 / 影响），每题 0 或 1 分，每 fixture 0–4 分，两臂满分各 32。
- **判分**：对照 `fixtures.mjs` 的 `truth` 字段，由**独立于作答的评分代理**逐题判（0/1 + 一句理由），Lead 复核。作答代理看不到 `truth`。

### 模型替换（如实记账）

计划用 `minimax-cn/MiniMax-M3.1-Flash`（AGENTS.md 的首选）。本会话里该路由不可用——

```

```

`minimax-cn` 在本会话没有可用模型（`list_subagent_models` 返回空），故按 AGENTS.md 的降级条款改用 `zai-coding-cn/glm-5.3-flash`，**两臂同模型**，比较依然公平。

## 判分口径

| 题 | 判对的条件 |
|---|---|
| Q1 定位 | 命中**函数名**；涉及多个函数时必须**全部**命名，模型明说看不到 → 0（文件名对是加分，不扣分） |
| Q2 语义 | 说到**语义变化本身**；「改了一行代码」不算 |
| Q3 条件 | 给出**可判定的条件**（分支 / 比较 / 阈值） |
| Q4 影响 | 给出**方向**（行为等价 / 只影响某分支 / 影响调用者）并说清依据 |

两个陷阱（`fixtures.mjs` 的 `truth` 写得很具体）：

- **行为等价类**（F4：六个判定条件重排）说成「有影响」算错；
- **有影响类**（F1 / F3 / F5）说成「完全等价」算错。

## 结论

1. **唯一变量只有呈现形态。** 两臂的 diff **主体行完全相同**（同一批上下文行与 ± 行），差的是框架：文件头 + 段头（行区间 + 作用域名）取代了裸行 + ` ... ` 省略行。所以这个实验量的是「框架值不值」，不是「diff 质量值不值」。
2. **收益集中在「定位」。** old 臂 8 题里 5 题答不出函数名；new 臂 8/8 全部命中（段头总是写着作用域名）。
3. **old 臂能不能答出取决于运气。** 改点恰好落在函数声明行后 3 行内时，diff 里正好有声明行（F3、F4 命中）；否则整个函数名在 diff 里**根本不存在**（F1、F2、F5、F7 答「从 diff 看不出来」）。F8 更糟：中间那个函数名被 ` ... ` 省略行吞掉，模型只能回答「一个函数名被省略号折叠的函数」。这正是「有时候读得懂、有时候完全读不懂、而且不知道为什么」的机制。
4. **语义 / 条件 / 影响三题两臂几乎无差。** 因为两臂的 diff 主体是同一批行，模型本来就能读出来。⇒ 本次形态改动买到的是「知道改的是哪个函数」，**不是**「自动读懂分支逻辑」。
5. **局限（如实记账）**：单模型（`zai-coding-cn/glm-5.3-flash`）、8 个 fixture、每格一次作答，无重复采样、无显著性检验；「哪个闭合对应哪个闭合」没有单独设题（只在 Q2/Q3 里间接依赖读懂分支结构）；F7 的参考答案在判分前被修正过一次（truth q1 由 `elideImports` 改为 `importRunSpans`——全仓库 grep 不到 `elideImports`，真实外层函数是 `src/ast/elide.ts` 的 `importRunSpans`），修正后重新判分。
6. **`~` 标记没有被实验覆盖**：作答代理是照着 diff 文字作答，不是照抄锚点，8 份作答里没有一次误抄。它是照着「误抄旧锚点 → 拿到已失效的锚点」这条风险加的，属设计防御而非实验结论。
7. **段粒度仍由既有 `hashline.context_lines` 决定**（默认 3）：调大 → 一大段覆盖整个函数；调小 → 远处的改动拆成多段，每段各带自己的段头与作用域名。
