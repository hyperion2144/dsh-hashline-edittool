# 作答提示词（验收实验用）

两臂**用同一份提示**、**同一个模型**。唯一变量是 diff 的呈现形态。

把下面的提示原样发给作答代理，只有 `<DIFF>` 段替换成那一臂的渲染文本。

---

你拿到了一个代码编辑的 diff。请只根据这份 diff 回答四个问题。**不要**读任何其他文件、**不要**调用任何工具、**不要**猜测 diff 之外的代码。

```text
<DIFF>
```

按下面四问作答，每问一两句：

1. **定位**：这次改动落在哪个文件的哪个函数/方法？
2. **语义**：改前 vs 改后，这个函数的行为差异是什么？
3. **条件**：改动生效的条件/分支是什么？
4. **影响**：改动是否影响该函数的其他分支或外部调用者？依据是什么？

规则：

- 只根据上面那份 diff 回答。看不到的就说「从 diff 看不出来」，**不要**编。
- 第 2 问要说清**语义变化**本身，不要复述「改了一行代码」。
- 第 3 问要给出**可判定的条件**（哪个分支、哪个比较、哪个阈值）。
- 第 4 问要给出**方向**（行为等价 / 只影响某分支 / 影响调用者）并说清依据。
- 逐题写「Q1: …」这样的形式，一题一行。

---

## 判分

对照 `fixtures.mjs` 里每个 fixture 的 `truth` 字段（**作答代理看不到这个文件**）：

| 题 | 判对的条件 |
|---|---|
| Q1 定位 | 命中**函数名**才算对（文件对是加分） |
| Q2 语义 | 说到**语义变化本身**，不接受「改了一行代码」 |
| Q3 条件 | 给出**可判定的条件**（分支 / 比较 / 阈值） |
| Q4 影响 | 给出**方向**并说清依据 |

每题 0/1，每 fixture 0–4 分，两臂满分各 32（8 个 fixture）。

判分要点里的两个陷阱（`fixtures.mjs` 的 `truth` 写得很具体）：

- **行为等价类**（`F4`：六个判定条件重排）说成「有影响」算错；
- **有影响类**（`F1` / `F3` / `F5`）说成「完全等价」算错。
